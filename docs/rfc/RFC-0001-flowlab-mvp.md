# RFC-0001 — FlowLab MVP

- Status: Draft
- Data: 2026-10-01

## Problema

Precisamos testar uma metodologia completa de engenharia sem iniciar por uma plataforma complexa.

## Proposta

Criar um sistema pequeno de solicitações com workflow e histórico.

## Funcionalidades

- criar solicitação;
- editar dados permitidos;
- definir prioridade;
- mudar status;
- registrar histórico;
- listar;
- filtrar;
- dashboard básico.

## Status iniciais

- New
- Open
- In Progress
- Blocked
- Done
- Cancelled

## Requisitos não funcionais

- execução local;
- persistência local;
- custo recorrente R$ 0,00;
- logs;
- health check;
- testes;
- código rastreável;
- documentação mínima útil.

## Fora de escopo

- DevMethod Lab;
- EVE;
- IA paga;
- multi-tenant;
- microserviços;
- Kubernetes;
- mensageria;
- infraestrutura cloud paga;
- autenticação corporativa;
- analytics avançado.

## Critério de aceite da RFC

A RFC será considerada aceita quando o escopo for suficientemente pequeno para iniciar implementação sem comprometer a política Zero-Cost.
