# Definition of Ready

Uma tarefa está pronta para desenvolvimento quando:

- [ ] problema está descrito;
- [ ] resultado esperado está claro;
- [ ] critérios de aceite estão definidos;
- [ ] dependências estão identificadas;
- [ ] impacto de custo foi verificado;
- [ ] riscos principais foram avaliados;
- [ ] não existe dúvida bloqueadora;
- [ ] a tarefa cabe em uma unidade pequena de implementação.

Itens que não atendem isso permanecem em descoberta/refinamento.
