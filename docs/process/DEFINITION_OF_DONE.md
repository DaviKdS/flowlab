# Definition of Done

Uma tarefa é considerada concluída quando:

- [ ] critérios de aceite foram atendidos;
- [ ] código está versionado;
- [ ] testes necessários foram criados/atualizados;
- [ ] testes relevantes passam;
- [ ] documentação afetada foi atualizada;
- [ ] nenhuma regressão conhecida foi introduzida;
- [ ] custo permanece dentro da política Zero-Cost;
- [ ] evidências estão rastreáveis por Issue/PR/commit/teste;
- [ ] não há débito crítico escondido;
- [ ] mudança está pronta para release ou já foi liberada.
