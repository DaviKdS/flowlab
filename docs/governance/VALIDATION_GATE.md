# FlowLab Validation Gate

O gate ocorre após uma versão estável do FlowLab.

## Critérios

- [ ] O produto atingiu o escopo definido.
- [ ] O método melhorou rastreabilidade.
- [ ] ADRs registraram decisões realmente úteis.
- [ ] RFCs foram úteis para mudanças relevantes.
- [ ] Issues ajudaram no controle de trabalho.
- [ ] Pull Requests trouxeram valor de revisão/rastreabilidade.
- [ ] Testes evitaram ou detectaram regressões.
- [ ] CI trouxe benefício proporcional ao overhead.
- [ ] Documentação foi utilizada de fato.
- [ ] O processo permaneceu simples o suficiente.
- [ ] O projeto permaneceu em R$ 0,00 de custo recorrente.
- [ ] Nenhuma cobrança automática foi habilitada.
- [ ] O método seria reutilizado em outro projeto.

## Decisões

### GO
Há evidência suficiente de valor. Pode-se abrir uma avaliação separada para DevMethod Lab + EVE.

### ITERATE
Há valor, mas um ou mais elementos do método geraram overhead ou falharam. Criar FlowLab v2 antes de expandir.

### STOP
O método não produziu benefício suficiente para justificar sua continuação.

## Autoridade

A decisão final é humana. IA pode resumir evidências, mas não aprova o avanço.
